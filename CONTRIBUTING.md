# Contributing

Everyone participating is expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).

Forking is welcome. The project is GPL-3.0: a fork stays open source under the same license. Contributions are accepted under the same license.

To contribute directly to this repo, open an issue or discussion first describing what you'd like to work on, before sending a pull request.

This project is maintained by one person, occasionally, alongside a full-time job and plenty of other things outside programming, so response times can be slow and unsolicited PRs may sit unreviewed for a while. Opening an issue first avoids wasted effort on both sides.
